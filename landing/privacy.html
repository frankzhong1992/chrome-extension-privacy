Privacy Policy

X Video Downloader · Last updated: 2026-09-26

Summary

X Video Downloader does not collect, sell, or transmit personal data to the developer. There is no account system and no analytics SDK.

Data handled locally

  • Quality preference — stored in Chrome storage on your device so the extension remembers Best / ~720p / ~480p.
  • Downloaded files — saved through the Chrome Downloads API to your computer’s downloads folder.

Network requests

When you choose to download a video, the extension may contact:

  • cdn.syndication.twimg.com — public media metadata
  • x.com / api.x.com — optional logged-in GraphQL fallback using cookies already in your browser (auth_token, ct0). These cookies are not uploaded to the developer.
  • video.twimg.com — fetch the MP4 file
  • abs.twimg.com — occasionally refresh X client query IDs

Permissions

The extension requests only the permissions needed to show download controls on X, resolve media URLs, remember settings, and save files.

Children

This extension is not directed at children under 13.

Changes

If this policy changes, the “Last updated” date above will be revised.

Contact

For privacy questions, open an issue in the project repository where you obtained the extension, or contact the publisher email shown on the Chrome Web Store listing.
