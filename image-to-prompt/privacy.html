Image to Prompt privacy policy

Updated October 3, 2026

Image to Prompt reads a web image only after you right-click it and choose “Generate Prompt”.

Stored on this device

Your API keys, selected provider, model names, and prompt language are saved in chrome.storage.local. They remain in this browser. Clear key removes the key for the provider you are viewing. Uninstalling the extension removes the saved settings.

Sent to a provider

The selected image and that provider’s API key go directly from this browser to the provider you choose:

  • OpenAI at api.openai.com
  • Anthropic at api.anthropic.com
  • Google at generativelanguage.googleapis.com

The developer does not receive or store the image or the key. This data is not sold.

Cookies

The image is requested without cookies first. Cookies for that image’s site are sent only when the image cannot be read without them. Those cookies are not forwarded to the AI provider.

Page access

Broad site access is used to download the image you clicked, including images hosted on another domain. A script runs in the page only after that click, to read blob images and images the download cannot reach. It does not change the page.

Contact

Use the developer email shown on the Chrome Web Store listing for this extension.
